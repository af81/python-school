# 🔁 Flow Control - Bedingungen & Schleifen

## if else

Wenn ein bestimmter Code nur ausgeführt werden soll, wenn eine bestimmte Bedingung erfüllt wird, dann braucht man ein `if` Statement.

Nehmen wir das Beispiel bei der **Notervergabe** bei einer Prüfung:

1. Schüler*in hat mehr als 60 Punkte: Note 6
2. Schüler*in hat mehr als 50, aber weniger als 60 Punkte: Note: 5
3. Schüler*in hat mehr als 40, aber weniger als 50 Punkte: Note: 4
